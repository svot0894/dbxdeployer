# Deployable Objects

This directory contains objects that require a deployment process in Databricks. These objects can be deployed through:

- SQL-based deployments
- API-based deployments

## Types of Deployables

1. SQL-based objects:
    - Catalogs
    - Functions
    - Schemas
    - Tables
    - Views
    - Volumes

2. API-based objects:
    - Jobs
    - Permissions

## Usage

Refer to specific object documentation for deployment instructions and requirements.
